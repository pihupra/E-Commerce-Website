# E-Commerce Website

![E-Commerce Demo](website/images/product1.jpg) <!-- Replace with a screenshot of your website -->

A **simple front-end e-commerce website** built with HTML, CSS, and JavaScript.  
This project is fully functional in the browser and ready to run in **GitHub Codespaces** or VS Code with Live Server.

---

## Features

- Responsive and visually clean design  
- Product listing with images, name, and price  
- Interactive **Add to Cart** functionality  
- Real-time cart total calculation  
- Easy to add new products  
- Fully web-based — no backend required
